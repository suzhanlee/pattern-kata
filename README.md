## 🚀 시작하기

1. 인프라 실행
```bash
docker-compose up -d
```

2. 원하는 주차로 이동
```bash
cd week01-transaction-basics
```

3. 학습 가이드 읽기
```bash
cat README.md
```

4. 실습 시작!

## 🎓 학습 원칙

이 카타는 "생각하는 개발자의 길 - 38개 패턴 언어"를 기반으로 합니다.

- **TinyExperiment**: 작은 실험으로 시작

- **AtomicCommit**: 의미 있는 단위로 커밋
- **ThinkingMirror**: 매주 회고 작성
